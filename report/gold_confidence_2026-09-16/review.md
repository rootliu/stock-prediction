> 历史实验：此报告基于合并远端 5f12f9b 之前的模型，不能作为当前 v2 结果。当前报告见 review_v2.md。

## 结论

重构置信度语义与观望机制，而不是人为提高百分数。价格模型及 guard 保持原样，保留环境变量回退。
新概率层标记 experimental_not_validated；短期有改善，长期尚不合格，不应将其作为高确定性交易信号。

最初找到的生产报告也是 9/15 晚间生成，不能称其为 9/16 实盘已验证结果。

## 问题与修正

1. 旧 confidence 是分类器偏离 50% 的程度、历史准确率与期限/风险折扣混合值，不是概率。现在明确分离 legacy_confidence_score。
2. 原分类器看涨概率可能与价格 guard 后方向相反。新 confidence 取最终价格方向对应概率，并将冲突标记为观望。
3. 校准不能混入训练标签。校准起点为 split+horizon，且每 horizon 个样本取一个，避免标签重叠带来的虚假样本量。
4. 采用同一个全局分类器生成历史校准分数和实时分数，避免历史全局模型与实时分支模型不一致。
5. 涨/跌/平采用 +/-0.5 元统一口径；旧 sign 准确率保留作为对照。三分类准确率降低是口径变化，不是价格改变。
6. CSV、JSON、Markdown 和扁平 API 同步输出三类概率、区间、样本量、观望原因。console 的涨跌金额改为相对同一基准。

## 尚需解决

- 价格模型原有 80/20 评估未做 purge；新概率校准单独剔除了重叠，但没有修订旧价格模型历史指标。
- COMEX 等按同日期拼接可能使用国内 16:00 尚未知的数据。需先记录 available_at、交易所时区及冻结行情快照，再重跑严格时间点回放。
- 下一阶段应该针对 guard 后最终方向积累滚动样本外预测，按期限校准其命中概率，而不只是依赖全局分类器分数。不得使用同一外层评估窗口训练后再汇报其成绩。
- 需要跨上涨、下跌、横盘的独立月份验证，并按日期/期限分块估计误差；更换校准器前保留当前和 legacy 两条回退路径。
- 当前不改变自动交易授权，也未修改 OpenClaw 的配置或 memory。

复现命令、字段单位和回退方式见仓库 README 的 Direction Confidence v1。
